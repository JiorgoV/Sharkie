# Sharkie 🦈

A 2D underwater browser game built with vanilla JavaScript and HTML5 Canvas.

## About

Play as Sharkie, an underwater shark fighting through jellyfish and a dangerous endboss. Collect coins and poison bubbles to power up your attacks and defeat the final enemy.

## Gameplay

- Swim through the ocean and avoid jellyfish
- Collect **coins** and **poison bubbles** along the way
- Find the endboss and defeat it in 5 hits
- The endboss speeds up as its health drops

## Controls

| Key | Action |
|-----|--------|
| ← → ↑ ↓ | Move Sharkie |
| D | Shoot bubble |
| Space | Shoot poison bubble |
| ESC | Pause / Resume |

Mobile and tablet controls are available via on-screen buttons in landscape mode.

## Features

- Smooth canvas-based animation with sprite sheets
- Parallax scrolling background
- Sound effects and background music with volume controls
- Pause menu and settings dialog
- Mobile responsive with touch controls
- Fullscreen support on touch devices

## Tech Stack

- Vanilla JavaScript (ES6, OOP)
- HTML5 Canvas API
- CSS3

## How to Run

Open `index.html` in a browser — no build step or dependencies required.
